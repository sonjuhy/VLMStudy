# GCP GPU 할당량 요청 및 트러블슈팅 기록

**작성일시**: 2026-07-05
**목표**: 7월 8일 프로모션 크레딧 만료 이전, VLMStudy 프로젝트의 Projector(P1, P2, P3) 모델 병렬 학습 완료를 위한 GCP GPU(L4) 인스턴스 확보

---

## 1. 초기 상태 및 문제점 진단
- **결제 계정 상태**: 2026년 4월 13일에 무료 체험판에서 유료 계정으로 정상 업그레이드됨 (잔여 크레딧 약 45만원).
- **GPU 쿼터 상태**: 서울 리전(`asia-northeast3`)의 개별 GPU 한도(L4, T4 등)는 1.0으로 존재하나, 프로젝트 전체 글로벌 한도인 **`GPUS_ALL_REGIONS`가 `0.0`으로 막혀 있어** 모든 GPU 인스턴스 생성이 불가능한 상태.
- **타임라인 이슈**: 단일 GPU VM에서 순차 학습 시 103시간 이상 소요되어 7월 8일 크레딧 만료 전 완료가 불가능함.

## 2. 해결 전략: 3개 모델 병렬 학습 (전략 A)
- 기한(약 72시간) 내 완료를 위해 **L4 GPU 2장이 장착된 VM(`g2-standard-24`) 3대를 동시에 가동**하는 병렬 학습 전략 채택.
- 예상 소요 시간: 약 34.6시간
- 예상 비용(Spot 기준): 약 100,000원 (On-demand 기준 약 286,000원)으로 45만원 예산 내 충당 가능.
- 이를 위해 `GPUS_ALL_REGIONS` 한도를 최소 **6**으로 상향 신청하기로 결정.

## 3. 할당량 증설 요청 트러블슈팅 과정

### 문제 1: 자동 전송 불가 에러
- **증상**: 할당량 페이지에서 6개 상향 요청 시 "이 리소스에서는 자동 전송을 사용할 수 없습니다. 복사하여 직접 제출하세요"라는 메시지 발생.
- **원인**: 신규 가입 및 개인 계정에서 고가 자원(GPU)을 처음 요청할 경우, 구글의 가상화폐 채굴 방지 정책에 의해 봇/자동 심사가 아닌 사람이 직접 심사(수동 검토)를 하도록 기본 설정되어 있음.

### 문제 2: 정규 고객지원 포털(Customer Care) 접근 차단
- **증상**: 케이스를 직접 만들기 위해 Customer Care에 접속했으나 "Customer Care 지원에는 조직 리소스가 필요합니다" 메시지 발생.
- **원인**: 사용자가 `@gmail.com` 기반의 독립형 프로젝트(조직 없음)를 운영 중이어서, 엔터프라이즈 환경용으로 개편된 정규 지원 포털 이용이 제한됨.

### 최종 해결: 퍼블릭 결제 지원 폼 우회 접수
- **조치**: 조직 리소스가 없는 개인 개발자도 사용할 수 있는 [공식 결제 및 할당량 퍼블릭 폼](https://support.google.com/cloud/contact/cloud_platform_billing)을 통해 티켓 제출 진행.
- **제출 내용**: 할당량 페이지에서 생성된 템플릿 메세지 원본과 함께, "7월 8일 크레딧 만료 전 VLM 모델 병렬 학습을 위해 L4 GPU 6개가 긴급히 필요하다"는 사유를 한국어로 명시하여 성공적으로 케이스 생성 및 심사 대기열 진입 완료.
